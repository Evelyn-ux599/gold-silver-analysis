公众号写作 Skill — Agent 驱动的内容生产系统

产品2026-05-15

什么是「写作 Skill」

不是写一篇文章，而是建立一套写作生产系统。写一篇文章是任务思维，建一个 Skill 是资产思维 — 一次定义、持续产出、无限迭代。

Skill 架构（5 模块）

1. 人设 Skill

  • Vera：商业经济背景的年轻超级个体，冷静、锐利、数据驱动
  • 核心价值主张：「用资本家视角拆解信息差，帮普通人提前 1-3 年看清趋势」
  • 目标受众：有投资意识但不专业的年轻高认知人群

2. 选题 Skill

三条信息差主线，交叉挖掘选题：

  • AI 产业链：芯片 / 算力 / 数据 / 应用 / 安全 5 环节拆解
  • 能源变革：核聚变、长时储能、光伏
  • 金融市场：期权、机构动向、宏观政策

3. 标题 Skill（三种策略自动轮换）

类型策略案例
悬念式好奇心驱动点击「AI Agent 爆发前夜：正在发生的算力权力转移」
反常识别颠覆常规认知「核聚变不是30年后的事：供应链已经开始接单」
数据冲击式硬数据开道「纳斯达克的期权暗语：机构用期权预告涨跌的底层逻辑」

4. 结构 Skill（6 段式模板）

  1. 开场钩子（150-250字）：故事/数据/反问
  2. 认知铺垫（200-300字）：为什么重要、多数人错在哪
  3. 分层拆解（3-5 小节）：每节 1 个数据点 + 信息差卡片
  4. 信息差速览表（4-6 行关键数据）
  5. 结尾升华 + CTA（150-200字）：金句 + 互动引导
  6. 免责声明

5. 视觉 Skill（封面自动配色）

主题主色触发关键词
科技翠绿+青蓝AI、芯片、算力、Agent
金融金橙+暗红期权、投资、市场、基金
政策深蓝+白政策、监管、央行
能源翠绿+白储能、核聚变、光伏

为什么这是「Agent 复利」的核心

  • 可自动化：有清晰模板后，AI Agent 可独立完成从选题到成文的 80%
  • 可迭代：跟踪阅读量/分享率数据 → 回头优化 Skill → 越写越好
  • 可积累：每写一篇都是资产的增加，边际成本递减

Skill vs. 任务

任务思维Skill 思维
行为我今天写了一篇文章我建立了一套写作系统
持续性明天需要重新开始明天自动产出一篇
改进方式每次从零感受数据驱动迭代模板
杠杆1:11:N

第一天产出

Skill 建立后，一天内产出 4 篇完整长文 + 封面：

  1. AI Agent 爆发前夜
  2. 纳斯达克期权暗语
  3. 长时储能：能源革命最后拼图
  4. 核聚变供应链已开始接单

这就是 Skill 的杠杆效应：一次定义 → 批量产出。
