## 项目概述

一个面向小资金的期权信用价差分析平台。聚焦 QQQ（纳指100 ETF）和 SLV（白银 ETF），通过 0-3 DTE 信用价差策略实现高胜率交易。接入 Yahoo Finance 真实数据，支持纸上模拟交易验证策略。

## 核心架构

```
├── src/app/
│   ├── dashboard/     # 实时报价 + IV Rank + 账户摘要
│   ├── options/       # 完整期权链查看器（含 Greeks）
│   ├── scanner/       # ★ 信用价差扫描器（核心）
│   ├── simulator/     # P&L 模拟器 + Greeks 衰减
│   ├── journal/       # 模拟交易日志 + 胜率统计
│   └── calculator/    # 仓位计算器（Kelly 公式）
├── src/lib/
│   ├── black-scholes.ts   # Greeks 计算引擎
│   ├── spread-calculator.ts # 价差扫描算法
│   ├── yahoo-finance.ts   # Yahoo Finance v3 API 封装
│   ├── trade-storage.ts   # IndexedDB 交易存储
│   └── cache.ts           # LRU 缓存层
└── src/components/    # React 组件（深色交易终端风格）
```

## 技术亮点

### Black-Scholes 期权定价引擎

纯 TypeScript 实现累积正态分布函数，客户端实时计算 Delta、Gamma、Theta、Vega、Rho 五个希腊值。无需后端计算，毫秒级响应。

### 信用价差扫描算法

自动扫描期权链中所有 OTM 合约，按 Delta、DTE、价差宽度三维过滤，综合 PoP × 盈亏比打分排序，一键生成模拟交易。

### 真实数据 + 本地模拟

- Yahoo Finance 实时美股期权链数据（15分钟延迟）
- IndexedDB 本地存储交易记录，无需数据库
- 自动统计胜率、盈亏比、利润因子、净值曲线

### 风险管理系统

内置 Kelly 公式仓位计算器，默认 $3,000 本金 / 单笔最高 5% 风险 / 最多 2 个并发仓位。

## 策略逻辑

| 策略 | 标的 | Delta | DTE | 理论胜率 |
|------|------|-------|-----|---------|
| Bull Put Spread | QQQ/SLV | 0.08-0.18 | 0-3 | 82-92% |
| Bear Call Spread | QQQ/SLV | 0.08-0.18 | 0-3 | 82-92% |

## 技术栈

- **Next.js 16** + TypeScript + TailwindCSS v4
- **yahoo-finance2 v3**: 美股数据源
- **Recharts**: 盈亏曲线可视化
- **IndexedDB**: 本地交易日志存储
- **React Query**: 数据缓存与轮询

## 成果

一个完整的期权分析决策工具，从数据获取、希腊值计算、策略扫描到模拟执行和绩效统计形成闭环，用于验证高胜率短期信用价差策略的可行性。

## 什么是「写作 Skill」

不是写一篇文章，而是建立一套**写作生产系统**。写一篇文章是任务思维，建一个 Skill 是资产思维 — 一次定义、持续产出、无限迭代。

## Skill 架构（5 模块）

### 1. 人设 Skill
- **Vera**：商业经济背景的年轻超级个体，冷静、锐利、数据驱动
- 核心价值主张：「用资本家视角拆解信息差，帮普通人提前 1-3 年看清趋势」
- 目标受众：有投资意识但不专业的年轻高认知人群

### 2. 选题 Skill
三条信息差主线，交叉挖掘选题：
- **AI 产业链**：芯片 / 算力 / 数据 / 应用 / 安全 5 环节拆解
- **能源变革**：核聚变、长时储能、光伏
- **金融市场**：期权、机构动向、宏观政策

### 3. 标题 Skill（三种策略自动轮换）
| 类型 | 策略 | 案例 |
|------|------|------|
| 悬念式 | 好奇心驱动点击 | 「AI Agent 爆发前夜：正在发生的算力权力转移」 |
| 反常识别 | 颠覆常规认知 | 「核聚变不是30年后的事：供应链已经开始接单」 |
| 数据冲击式 | 硬数据开道 | 「纳斯达克的期权暗语：机构用期权预告涨跌的底层逻辑」 |

### 4. 结构 Skill（6 段式模板）
1. **开场钩子**（150-250字）：故事/数据/反问
2. **认知铺垫**（200-300字）：为什么重要、多数人错在哪
3. **分层拆解**（3-5 小节）：每节 1 个数据点 + 信息差卡片
4. **信息差速览表**（4-6 行关键数据）
5. **结尾升华 + CTA**（150-200字）：金句 + 互动引导
6. **免责声明**

### 5. 视觉 Skill（封面自动配色）
| 主题 | 主色 | 触发关键词 |
|------|------|-----------|
| 科技 | 翠绿+青蓝 | AI、芯片、算力、Agent |
| 金融 | 金橙+暗红 | 期权、投资、市场、基金 |
| 政策 | 深蓝+白 | 政策、监管、央行 |
| 能源 | 翠绿+白 | 储能、核聚变、光伏 |

## 为什么这是「Agent 复利」的核心

- **可自动化**：有清晰模板后，AI Agent 可独立完成从选题到成文的 80%
- **可迭代**：跟踪阅读量/分享率数据 → 回头优化 Skill → 越写越好
- **可积累**：每写一篇都是资产的增加，边际成本递减

## Skill vs. 任务

| | 任务思维 | Skill 思维 |
|------|------|------|
| 行为 | 我今天写了一篇文章 | 我建立了一套写作系统 |
| 持续性 | 明天需要重新开始 | 明天自动产出一篇 |
| 改进方式 | 每次从零感受 | 数据驱动迭代模板 |
| 杠杆 | 1:1 | 1:N |
