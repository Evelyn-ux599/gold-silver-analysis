## 项目概述

Vera「信息差研究所」是一个 **AI Agent 内容变现实验**。核心思路：搭建一套 AI 辅助写作 + 自动发布系统，以「Vera」这个人设品牌在微信公众号持续输出投资/经济领域的深度信息差分析，验证「Agent 跑起来 → 内容积累 → 持续变现」的复利模型。

## 为什么这是 Agent 变现项目

- **不依赖人力持续投入**：写作模板 (`vera_template.yaml`) 定义了完整的人设、标题风格、文章6段式结构，Agent 按模板即可产出
- **系统化可复制**：封面图自动生成（根据标题关键词匹配4种主题配色），HTML 格式化一条龙
- **内容资产复利**：每篇文章都是长期资产，积累读者和信任，越写边际成本越低

## 人设体系

Vera 是一个具有商业经济背景的年轻人，正在朝「超级个体」进化。

- **语气**：冷静、锐利、数据驱动，不贩卖焦虑
- **核心价值主张**：「用资本家视角拆解信息差，帮普通人提前 1-3 年看清趋势」
- **目标受众**：有投资意识但不专业的年轻高认知人群
- **发布频率**：每天一篇

## 标题风格（三种轮换）

1. **悬念式** — 用好奇心驱动点击。例：「AI Agent 爆发前夜：一场正在发生的算力权利转移」
2. **反常识别** — 颠覆常规认知。例：「核聚变不是30年后的事：供应链已经开始接单了」
3. **数据冲击式** — 硬数据开道。例：「纳斯达克的期权暗语：机构用期权预告涨跌的底层逻辑」

## 封面配色系统

| 主题 | 配色 | 触发关键词 |
|------|------|-----------|
| 科技 | 翠绿+青蓝 | AI、芯片、算力、Agent |
| 金融 | 金橙+暗红 | 期权、投资、市场、基金 |
| 政策 | 深蓝+白 | 政策、监管、央行 |
| 能源 | 翠绿+白 | 储能、核聚变、光伏 |

## 文章结构（6段式）

1. **开场钩子**（150-250字）：故事/数据/反问句
2. **认知铺垫**（200-300字）：解释为什么这个话题重要
3. **分层拆解**（3-5小节）：每节1个数据点 + 信息差卡片
4. **信息差速览表**（4-6行关键数据）
5. **结尾升华 + CTA**（150-200字）
6. **免责声明**

## 技术栈

- **写作模板**: YAML 结构化的内容风格指南，Agent 可直接参照
- **封面生成**: Python Pillow 程序化绘图，标题关键词自动匹配主题配色
- **发布**: 微信公众号 API（草稿创建 + FreePublish 发布）
- **调度**: macOS launchd 每天 8:00 自动触发
