## 做了什么

今天从零开始搭建了一个完整的个人作品集网站，用于展示我的所有项目成果和每日动态。

### 技术选型

选择了 Next.js 作为框架，因为：

1. **SSG 静态生成**：所有内容从 Markdown 文件编译，无数据库依赖，部署简单
2. **React 生态**：组件化开发，易于维护和扩展
3. **App Router**：最新的路由方案，支持 Server/Client Components 分离

### 核心设计

- **暗色主题**：沿用之前项目的视觉风格，深蓝背景 + 蓝色/紫色渐变光球装饰
- **内容驱动**：所有项目和日志以 Markdown 文件存储，通过 gray-matter 解析 frontmatter
- **结果导向**：每条日志都有 `result` 字段，强调当天具体产出

### 实现的功能

- 首页 Hero 大屏 + 最近7天动态时间线 + 精选项目卡片
- 项目页面：分类筛选画廊（编程/AI/设计/写作/其他）
- 每日日志：按月归档，支持前后篇导航
- 响应式设计：移动端适配
- 404 页面

## 收获

学会了 Next.js 16 的 App Router 模式，掌握了 Server Components + Client Components 的合理分工：数据获取在服务端，交互状态在客户端。
