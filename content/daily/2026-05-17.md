## 做了什么

### Hermes Agent 本地部署

成功将 Hermes Agent 部署到本地 macOS，CLI 直接运行，可：
- **读写本地文件**（iCloud 项目目录直接操作）
- **操作 mac0S 桌面**
- **微信公众号草稿自动提交**（纯 Python stdlib 封装，零外部依赖）
- **QQ + iCloud 双通道**：QQ 发指令，iCloud 项目文件直接读写

意义：之前 Agent 跑在云端，只能通过 QQ 收发文字。现在 Agent 在我自己的电脑上，可以读写代码、操作桌面、提交公众号——Agent 的自动化能力从「只聊天」升级为「真干活」。

### 公众号草稿自动化

新增 `wechat-vera-writer` Skill（Hermes Skill 系统），实现：
1. 用户给选题 → Agent 研究数据
2. 按 Vera 风格撰写深度文章（6段式 + 论文式引用）
3. 自动生成封面图并上传微信
4. 提交到微信公众号草稿箱

今天完成第一篇：「人形机器人真正值钱的不是关节，是触觉」
- 三个细分赛道拆解：MEMS压力传感器 / 柔性电子皮肤 / 六维力传感器
- 8条参考文献，论文式 [1][2] 引用
- 已保存至公众号草稿箱

### 复利站更新

- SKILLS 数组从 6 个更新至 7 个（新增 Hermes Agent 本地部署）
- Hero 指标：3→7 Agent/Skill
- 新增本日 daily log
- 封面技能描述优化：纯像素渲染零外部依赖

## 收获

Hermes 部署到本地是 Agent 复利的关键转折点——从「只能聊天」到「能操作电脑」。现在 7 个 Skill 在跑，下一步：修复 venv 路径 + plist 定时任务 + 优化封面图设计跟上已有的文章风格。

每多一个 Skill，Agent 就多接管一块工作。今天新增 Hermes Agent 本地部署 + wechat-vera-writer Skill = +2。当 Skill 积累到 10 个，人只需要做决策，剩下的 Agent 自动跑。
